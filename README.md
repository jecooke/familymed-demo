# FamilyMed — live demo

A family tree of known diagnoses, and the computed propensity for relatives
who don't have one yet. This repository holds only the compiled, static
web build (WebAssembly + a small JS loader) — no source code.

Runs entirely in your browser: nothing you enter is ever sent to a server.
Your data lives only in the files you choose to open and save on your own
device.
